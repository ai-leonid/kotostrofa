# 🐱 КОТОСТРОФА v3

> **3D-игра в браузере:** ты — кот, хозяева ушли на работу, и у тебя есть ограниченное время, чтобы устроить в квартире тотальный разгром. Каждая комната — это отдельный уровень со своими квестами, порогами ущерба и запертыми дверями.

Вся игра создана **100% процедурно кодом**: без пререндеренных картинок, текстур, 3D-моделей или аудиофайлов.

---

## ⚡ Быстрый старт

Проект собран на современном стеке **Vite + TypeScript**:

```bash
# 1. Установка зависимостей
npm install

# 2. Запуск в режиме разработки (Dev Server с HMR)
npm run dev
# Игра откроется по адресу: http://localhost:5173

# 3. Сборка оптимизированного продакшен-бандла (dist/)
npm run build

# 4. Предпросмотр сборки
npm run preview
```

## 🎮 Как играть

Квартира состоит из 4 последовательных комнат-уровней:  
**Гостиная → Кухня → Ванная → Спальня**.  
Кот начинает в гостиной, проходы в остальные помещения перекрыты физическими дверями.

### Прохождение комнаты:
1. **Выполнить обязательный квест** комнаты (карточка с пометкой «обяз.» в HUD).
2. **Нанести ущерб** не меньше целевого порога комнаты (шкала прогресса под таймером):
   - **Гостиная:** 18 000 ₽ (старт: 45 с)
   - **Кухня:** 24 000 ₽ (+25 с)
   - **Ванная:** 6 000 ₽ (+20 с)
   - **Спальня:** 8 000 ₽ (+15 с)

Как только условия выполнены:
- Дверь в следующую комнату со скрипом распахивается;
- На миникарте и в 3D-мире загорается маяк навигации и счётчик дистанции;
- На таймер начисляется прибавка времени;
- Выплачивается **премия Синдиката за скорость**: весь текущий остаток времени конвертируется по курсу **50 ₽/сек** и добавляется в общий счёт.

### Геймплейные особенности 3.0:
- **⭐ Бонус-объект дня (Daily Special):** в каждой партии случайно выбирается один предмет — он получает множитель **×2.5 к стоимости**, сияющий золотой ореол и плашку в HUD.
- **🔥 Режим «Ультра-хаос»:** при достижении ранга КОТОСТРОФА (серия 100+ комбо) на 10 секунд активируется супер-режим: все предметы дают ×1.5 очков, кот ускоряется, а края экрана заливает неоновый bloom.
- **🪢 «Лапа-лассо»:** удерживайте `Q` (>220 мс) рядом с предметом для захвата, прицельтесь камерой и отпустите для броска со скоростью 12 м/с.
- **🤖 Робот-пылесос «Жорка-3000»:** патрулирует открытые комнаты и сбивает комбо при столкновении. Имеет полоску 100 HP. Бросок предмета лапой-лассо наносит роботу критические **50 HP урона**. Уничтожение робота даёт джекпот **+12 000 ₽**!
- **🌪️ Случайные события «Катастрофа»:** каждые 20–30 секунд происходят неожиданные катаклизмы — *Землетрясение* (тряска и падение посуды), *Гроза* (вспышки молний и мигание света), *Звонок телефона*.
- **🏆 Мета-квесты партии:** «Гроза роботов», «Неостановимый» (комбо 50+), «Звезда хаоса» (разбить Daily Special) — отображаются на финальном экране.
- **💥 Мега-разрушения:** распахивающийся холодильник с едой, срыв карниза со шторами и пылью, брызги аквариума с живой рыбкой, скользкие лужи с дрифтом кота, цепные реакции («СТРАЙК!») и кинематографичный hit-stop (35 мс).

## 🕹️ Управление

### Клавиатура и мышь:
| Клавиша / Ввод | Действие |
|---|---|
| **WASD** / **Стрелки** | Перемещение относительно направления камеры |
| **Мышь** | Свободный обзор от третьего лица (захват курсора кликом) |
| **Shift** | Спринтерский рывок с ускорением и расширением FOV |
| **Space** | Прыжок на столы, диваны, полки и подоконники |
| **ЛКМ** / Короткий клик **Q** | Быстрый взмах лапой (конусный удар по предметам) |
| **Удержание Q (>220 мс)** | **«Лапа-лассо»:** захват предмета, прицел лучом и бросок вперед |
| **E** / **M** | Громкое мяуканье (ударная звуковая волна, разбрасывающая лёгкие предметы) |
| **Точение когтей** | Удержание рядом с коврами, диваном или когтеточкой |
| **Esc** | Пауза игры |

### Мобильные устройства (Touch UI):
- **Виртуальный джойстик слева:** плавный бег (оттягивание до края — рывок);
- **Кнопки справа:** «ЛАПА», «МЯУ», «ПРЫЖОК»;
- **Свайп по экрану:** вращение камеры;
- **Щепотка (Pinch-to-zoom):** приближение/отдаление камеры.

## 🛠️ Технологический стек

- **[Vite 8.3](https://vitejs.dev/)** — современный сборщик, ES-модули, мгновенный HMR;
- **[TypeScript 5.9](https://www.typescriptlang.org/)** — строгая статическая типизация всех сущностей;
- **[Three.js 0.183](https://threejs.org/)** — 3D-сцена, процедурные меши, тени (`PCFShadowMap`), прожектор `SpotLight`;
- **[cannon-es 0.20](https://github.com/pmndrs/cannon-es)** — честная физика твердых тел, детерминированный цикл `FIXED_DT = 1/60`;
- **[mitt 3.0](https://github.com/developit/mitt)** — легковесная типизированная шина событий (EventBus);
- **HTML5 Canvas 2D** — процедурные текстуры (обои, паркет, плитка, bumpMap ткани), интерактивная миникарта, живой эмодзи-портрет кота 64×64;
- **WebAudio API** — процедурный синтез мяуканья, звона бьющегося стекла, ударов и фанфар;
- **localStorage** — сохранение рекордов, званий и истории партий.

## 🧪 Автоматизированное тестирование

В проекте реализован полный комплект из **26 автоматических тестов** на базе Puppeteer, покрывающий физику, геймплей, графику, квесты и сквозные сценарии:

```bash
# Запуск всех 26 тестов единым раннером:
npm test
# или: node test/run_all.js
```

### Ключевые тестовые сценарии:
```bash
node test/smoke.js             # Базовая проверка Three.js и cannon-es
node test/physics_ceiling.js   # Защита от вылета кота сквозь потолок (BUG-01)
node test/shard_bounds.js      # Проверка локализации осколков в комнате (BUG-02)
node test/scoring_integrity.js # Дедупликация начисления очков за 1 кадр (BUG-03)
node test/room_boundary.js     # Определение комнат на границах дверей A, B, V (BUG-04)
node test/restart.js           # Мгновенный перезапуск без перезагрузки страницы
node test/daily_special.js     # Механика предмета дня (множитель ×2.5, HUD)
node test/ultra_chaos.js       # Режим Ультра-хаос на комбо 100+
node test/lasso_throw.js       # Бросок предметов лапой-лассо со скоростью 12 м/с
node test/catastrophe.js       # Случайные события (Землетрясение, Гроза)
node test/hard_mode.js         # Хардкорный режим ?hard=1
node test/graphics_features.js # Процедурный портрет кота 64×64 и эффекты
node test/levels_e2e.js        # Полное прохождение всех 4 комнат до победы
node test/records.js           # Персистентность рекордов в localStorage
node test/mobile.js            # Мобильный тач-джойстик и сенсорные кнопки
node test/e2e.js               # Полная партия с ботом без ошибок в консоли
```

## ⚙️ Отладочные URL-параметры

Для тестирования и тюнинга доступны специальные флаги в строке адреса:

- `http://localhost:5173/?autostart=1` — мгновенный старт без клика по экрану приветствия;
- `http://localhost:5173/?autostart=1&bot=1&t=45` — запуск автономного бота на 45 секунд;
- `http://localhost:5173/?hard=1` — включение **хардкор-режима** (скрытый HUD, комбо-окно 0.6 с, кот-призрак);
- `http://localhost:5173/?unlock=all` — открыть все двери и комнаты со старта игры;
- `http://localhost:5173/?fast=1` — ускоренный рендеринг без теней для слабых видеокарт.
