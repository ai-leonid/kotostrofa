# КОТОСТРОФА

3D-игра в браузере: ты — кот, хозяева ушли на работу, и у тебя есть **одна минута**, чтобы разгромить квартиру. Но двери заперты: каждая комната — это уровень. Всё сгенерировано кодом: без нейросетевых картинок, видео и звука.

## Запуск

Открой `index.html` двойным кликом — работает офлайн, библиотеки лежат в `vendor/`.

## Как играть

Квартира из 4 комнат-уровней: **Гостиная → Кухня → Ванная → Спальня**. Кот начинает в гостиной, остальные двери заперты.

Чтобы пройти комнату, нужно:
1. выполнить **обязательный квест** комнаты (карточка с пометкой «обяз.»),
2. нанести ущерб не меньше **порога комнаты** (полоса под таймером).

Тогда комната засчитывается: открывается дверь в следующую комнату (светящаяся вывеска покажет куда), к таймеру добавляется время. Пороги растут, а бонусы времени уменьшаются — уровни усложняются. В каждой комнате есть 2–3 **опциональных квеста** (пометка «бонус») за дополнительные рубли. В пройденные комнаты можно возвращаться — там всё ещё можно ломать в общий счёт. Пройдёте все четыре — «КВАРТИРА РАЗГРОМЛЕНА!». Таймер дошёл до нуля — хозяева вернулись: итоговый экран со счётом, комнатами и званием.

**Премия за скорость.** Кот — агент Синдиката Хаоса: после каждой пройденной комнаты заказчик платит премию за оперативность — весь остаток времени на таймере в этот момент конвертируется по **30 ₽/с** и добавляется к итоговому счёту (идёт в рекорд). Чем быстрее комната, тем больше запас времени — и тем выше премия; торопись на всех уровнях, и набежит заметная сумма.

**Рекорды** сохраняются локально (localStorage): лучший счёт виден на стартовом экране, новый рекорд отмечается на финальном; вместе с рекордом хранятся максимумы по комнатам — пригодится для мультиплеера.

## Управление

| Клавиша | Действие |
|---|---|
| WASD / стрелки | бегать |
| Мышь | камера (третье лицо) |
| Shift | рывок |
| Space | прыжок (на столы, тумбы, полки) |
| ЛКМ / Q | удар лапой |
| E | мяукнуть, шоковая волна (M — запасная) |
| Esc | пауза |

**На телефонах и планшетах** появляются сенсорные элементы: плавающий джойстик слева (бег; до края — рывок), кнопки «ЛАПА», «МЯУ», «ПРЫЖОК» справа, свайп по экрану крутит камеру, щепотка меняет зум.

## Стек

- [three.js](https://threejs.org/) r147 — рендер (в `vendor/`, без сборки);
- [cannon.js](https://github.com/schteppe/cannon.js) 0.6.2 — физика;
- WebAudio API — процедурный звук (мяуканье, звон посуды, скрип дверей, фанфары);
- canvas-текстуры (пол, плитка, обои, картины) — без внешних файлов;
- localStorage — рекорды и история партий.

## Структура

```
index.html      — разметка, HUD, экраны, тач-UI
css/style.css   — интерфейс, сенсорное управление, мобильная адаптация
js/levels.js    — конфиг уровней: комнаты (AABB, пороги, бонусы времени), двери, порядок
js/save.js      — рекорды и история партий (localStorage)
js/world.js     — квартира: 4 комнаты, мебель, свет, двери уровней
js/props.js     — разрушаемые предметы (~80), осколки, рыбка, события для квестов
js/cat.js       — кот: меш из примитивов, анимации, управление
js/game.js      — счёт, комбо, квесты (12, движок событий), уровни, таймер, финал, рекорды
js/audio.js     — синтез звука
js/main.js      — bootstrap, ввод (клавиатура + тач), камера, цикл, бот для тестов
vendor/         — three.min.js, cannon.min.js (локально, офлайн)
```

## Тесты

```bash
npm install                 # puppeteer-core (для E2E)
node test/smoke.js          # проверка API cannon/three в node
node test/levels.js         # атрибуция очков комнатам, roomOf
node test/records.js        # рекорды: запись, персистентность, сломанное хранилище
node test/e2e.js            # бот, разрушения, финал, ошибки консоли
node test/levels_e2e.js     # прохождение цепочки 4 уровней до победы
node test/quest_e2e.js      # квест «Рыбный день»
node test/quest_fish_spawn.js # регрессия: рыбка спавнится на открытом полу
node test/quest_any_order.js  # регрессия: шаги квеста в любом порядке
node test/quest_bedroom.js    # квест «Тихий час»
node test/mobile.js           # мобильная адаптация: тач-UI, джойстик, камера
```

Для ручной отладки: `?autostart=1` (без стартового экрана), `?bot=1` (автобот), `?t=30` (длительность), `?unlock=all` (все двери открыты), `?fast=1` (без теней, для медленных машин) — напр. `index.html?autostart=1&bot=1&t=30`.
