# КОТОСТРОФА

3D-игра в браузере: ты — кот, хозяева ушли на работу, и у тебя есть **одна минута**, чтобы устроить в квартире максимальный хаос. Всё сгенерировано кодом: без нейросетевых картинок, видео и звука.

## Запуск

Открой `index.html` двойным кликом — работает офлайн, библиотеки лежат в `vendor/`.

## Управление

| Клавиша | Действие |
|---|---|
| WASD / стрелки | бегать |
| Мышь | камера (третье лицо) |
| Shift | рывок |
| Space | прыжок (на столы, тумбы, полки) |
| ЛКМ / Q | удар лапой |
| E | мяукнуть, шоковая волна (M — запасная) |
| Esc | пауза |

## Игровой цикл

- **Ущерб в рублях** за сбитые и разбитые предметы (~60 физических объектов: посуда, книги, ТВ, торшер, аквариум, стулья…). Честная физика: предметы падают, катятся, бьются и задевают друг друга.
- **Комбо**: цепочки разрушений в течение 2,5 с умножают урон (до ×3).
- **Побочный квест «Операция „Рыбный день“»** (2–3 шага, виден в HUD): запрыгни на кухонный стол → сбрось аквариум со столешницы → сожри рыбку. Награда +2 000 ₽.
- **Финал**: экран «Хозяева вернулись» — список разрушений, итоговый счёт ущерба и звание от «Ласкового пушистика» до «ЛЕГЕНДЫ КВАРТИРЫ».

## Стек

- [three.js](https://threejs.org/) r147 — рендер (в `vendor/`, без сборки);
- [cannon.js](https://github.com/schteppe/cannon.js) 0.6.2 — физика;
- WebAudio API — процедурный звук (мяуканье, звон посуды, всплеск, стук в дверь);
- canvas-текстуры (пол, плитка, картины) — без внешних файлов.

## Структура

```
index.html      — разметка, HUD, экраны
css/style.css   — интерфейс
js/world.js     — квартира: комнаты, мебель, свет, статика-физика
js/props.js     — разрушаемые предметы, осколки, рыбка
js/cat.js       — кот: меш из примитивов, анимации, управление
js/game.js      — счёт, комбо, квест, таймер, финальный экран
js/audio.js     — синтез звука
js/main.js      — bootstrap, ввод, камера, игровой цикл
vendor/         — three.min.js, cannon.min.js (локально, офлайн)
```

## Тесты

```bash
npm install            # puppeteer-core (для E2E)
node test/smoke.js     # проверка API cannon/three в node
node test/e2e.js       # E2E: бот играет, финал, ошибки консоли
node test/quest_e2e.js # E2E побочного квеста (3 шага)
```

Для ручной отладки есть query-параметры: `?autostart=1` (без стартового экрана), `?bot=1` (автобот), `?t=30` (длительность раунда), напр. `index.html?autostart=1&bot=1&t=30`.
